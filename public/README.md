# `/public` — static assets

Served verbatim from the site root by Vite. Nothing here is bundled, hashed, or
transformed, so reference these files by absolute path (`/favicon.svg`), never
by import.

| File | Purpose |
|---|---|
| `favicon.svg` | Browser tab icon |
| `aaindex_explorer_logo.png` | Logo used in the navbar and docs |
| `og.svg` | Source artwork for the social preview image |
| `og.png` | 1200×630 render of `og.svg`, referenced from `index.html` — social sites don't display SVG previews. Re-render it after editing the SVG |
| `robots.txt` | Crawler rules; points at `sitemap.xml` |
| `sitemap.xml` | **Generated** — do not edit by hand |

`sitemap.xml` is regenerated by `scripts/gen-sitemap.mjs`, which runs
automatically as part of `npm run build` (or on demand via `npm run sitemap`).

Because these files are cache-friendly and unversioned, changing one keeps its
URL — bump the filename if you need to bust a cache.
